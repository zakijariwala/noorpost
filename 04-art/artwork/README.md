# Artwork — delivered files

Finished illustration lands here, one file per item, named to match its spec:

```
envelope-03-person-print.png     # or .tif/.svg — source resolution, not a screenshot
envelope-03-event-print.png
envelope-03-sticker-sheet.png
...
companion-salman-person-print.png
```

**Naming matters:** it is how `04-art/print/` templates will pick art up when the
placeholder boxes are replaced, and how the card views in `docs/` will stop saying
"Placeholder — no artwork made yet".

## Before a file is accepted here

1. **Palette** — every colour in the fixed table in `design-system.md` §2, or a
   sanctioned exception recorded there. The Green Dome is currently the one open
   case.
2. **Ground** — warm ivory `#F3EDE1` or transparent. Not white; the stock is ivory.
3. **No faces, no figures** in any of the Fourteen. Faces are allowed only in the
   companions line.
4. **Set consistency** — prints that hang together (02/05/09 with 03 for Medina;
   04 with 11; 08 with 14) share light, line weight and composition logic.
5. **Resolution and bleed** — print size at 300dpi minimum, plus the bleed the
   chosen printer specifies. `04-art/print/README.md` notes bleed is not yet set.
