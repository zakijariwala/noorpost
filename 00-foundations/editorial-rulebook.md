# Editorial rulebook

Derived from PRD §7 and §8. Every rule here is checkable — it can be answered yes or no by someone holding the page. Rules that cannot be checked are opinions and do not belong in this file.

Use `checklist.md` to run an envelope through it.

---

## 1. The two-voice letter

### Marks and voices

| Rule | Check |
|---|---|
| L1 | Adult lines carry a filled circle ●. Child lines carry an open circle ○. |
| L2 | No names are printed. Not "Parent", not "Child", not the buyer's name. The marks do the work. |
| L3 | Adult lines carry narrative and anything over two sentences. |
| L4 | Child lines carry dialogue, questions and beats. Never exposition. |

### Counts

| Rule | Check |
|---|---|
| L5 | Total 330–370 words, counting both voices, excluding the title. |
| L6 | Six to nine child lines. Not five. Not ten. |
| L7 | Every child line is under 15 words. |
| L8 | At least one child line demands a response — the adult cannot continue reading until the child says something. |
| L9 | The last line is read together. Marked ●○. |
| L10 | Read aloud, unhurried, it runs four to four and a half minutes. Time it with a stopwatch, do not estimate. |

### Language

| Rule | Check |
|---|---|
| L11 | No word in a child line should stump an eight-year-old. See §2. |
| L12 | Arabic and proper nouns in child lines are allowed only if the child already meets them at madrasa — *Imam*, *Karbala*, *Kaaba*, *Makkah*, *Medina*, *Qur'an*, *masjid*. Anything else goes in an adult line first, where it can be explained in the sentence that carries it. |
| L13 | Child lines are set larger, in the display face. |

### What the letter does not do

| Rule | Check |
|---|---|
| L14 | The letter never builds to the death. Around eight of the fourteen end in poison in the traditional accounts; none of the fourteen letters ends there. |
| L15 | The letter stops before the hardest part. If the true ending is unbearable for a child, end the letter earlier and let the fact panel carry the fact. |
| L16 | No violence rendered in scene. Consequences may be named; methods, wounds and final hours may not. |
| L17 | No moral stated at the end. The session card asks the question; the letter does not answer it. |

## 2. The child-word test

**The list is Dolch plus Fry 1000, plus the madrasa vocabulary named in L12.** A word outside those lists in a child line needs a decision, recorded in the envelope's working file.

Three allowed outcomes:

1. **Swap it.** Almost always correct.
2. **Seed it.** The adult line immediately before uses the word in a sentence that makes it plain. Then the child line may use it.
3. **Keep it and mark it.** Only for words the envelope is genuinely about — *treaty* in envelope 02, *occultation* in envelope 10. One per envelope, at most. Two means the letter is aimed too high.

Words already ruled on, project-wide:

| Word | Ruling |
|---|---|
| treaty | Seed in envelope 02, then allowed |
| caliph | Adult lines only. Never in a child line. |
| occultation | Adult lines only, even in envelope 10 |
| martyr, martyred | Adult lines only |
| shrine | Allowed |
| pilgrim | Seed first |
| companion | Allowed |
| imamate | Adult lines and fact panels only |
| narrator, narration | Never. Use *someone who was there*. |

## 3. The fact panel

Full skeleton in `fact-panel-spec.md`. The rules that are editorial rather than structural:

| Rule | Check |
|---|---|
| F1 | Every claim is traceable to a row in `citation-sheet.md`. |
| F2 | No follower counts. No "people influenced". No population figures. No "the most X in history". |
| F3 | Facts that survive checking: the ruler of the day, the length of the imamate, named students, attributed compilations, what was happening elsewhere in the world that year. |
| F4 | Primary text cited with hadith or page number, printed small. |
| F5 | One woman, in the fixed slot, every envelope. Assignments in PRD §9. |
| F6 | Where an account is loved but undocumented, it is marked traditional **in the child's copy**, not only in the parent's. Wording in `standard-lines.md`. |
| F7 | Where communities differ, authority goes to the parent. Wording in `standard-lines.md`. |
| F8 | The death is the last line of the fact panel, and appears nowhere else in the envelope. |
| F9 | The death line names the fact and the actor and drops the method. No symptoms. No final hours. Approved wordings in `death-lines.md`. |

## 4. One new thing for the adult

**Non-negotiable.** It is the difference between discovering together and a parent performing.

| Rule | Check |
|---|---|
| A1 | Every envelope contains one fact a practising Shia adult is unlikely to already know. Named per envelope in PRD §9. |
| A2 | It is a fact, not a reflection. "Hurr means the free one" passes. "Hurr teaches us about courage" fails. |
| A3 | It is checkable. If it cannot be sourced, it is not the new thing. |
| A4 | It sits where the adult will hit it while reading aloud — an adult line in the letter, or the fact panel. Never buried on the sticker sheet. |
| A5 | Test: read it to three practising adults. If two already knew it, find another. |

## 5. The through-question

**Every issue answers one question: what did he do with the freedom he had?**

| Rule | Check |
|---|---|
| T1 | Name, in one sentence in the envelope's working file, how much room this Masoom had. Prison, house arrest, a watched street, an open teaching circle, a throne offered on conditions. |
| T2 | The letter shows what he did inside that room. |
| T3 | The envelope does not resolve into "he was patient". Patience is the frame of half the fourteen and explains none of them individually. |

## 6. Sessions

| Rule | Check |
|---|---|
| S1 | Every activity needs two roles. Anything one person can do alone fails the brief. |
| S2 | Type matches the assignment in PRD §9. Conversation ×7, Case File ×4, Mourning ×2, Open ×1. |
| S3 | **Conversation:** five questions. The adult answers first on one, marked. One is hard for an adult, marked. |
| S4 | **Case File:** the letter poses the question. Five evidence cards. The parent holds a sealed answer and opens it only when the child commits to an answer. |
| S5 | **Mourning:** one passage read aloud, one question, one instruction to sit quietly. No game. No points. No stickers — a pennant replaces the sticker sheet. |
| S6 | **Open:** no answer card, no five questions. Used once, for al-Mahdi. |
| S7 | No session requires anything not in the envelope, except a pen. |

## 7. Runtime

| Rule | Check |
|---|---|
| R1 | Total session about twenty-five minutes. |
| R2 | The letter is four to four and a half minutes of that. |
| R3 | The running order and the runtime print inside the flap. |
| R4 | Timed with a real family before the envelope is signed off, not estimated from the page. |

## 8. The collections

| Rule | Check |
|---|---|
| C1 | Three collections: fourteen hadith cards for the child's Qur'an, fourteen person prints for a wall, fourteen event prints for the calendar ring. Forty-two pieces, three destinations, one box. |
| C2 | The silsila runs in historical order. The envelopes run in calendar order. |
| C3 | **The segment number prints on the hadith card. The envelope number never does.** |
| C4 | Every event print carries the same punch position, so all fourteen clip onto one ring. |
| C5 | ~~No item outside the box ever carries a hadith card or an event print.~~ **Amended 2026-08-14 — see C5a and C6.** |
| C5a | **No item outside the box ever carries an event print.** The calendar ring stays box-only, and it is now the only collection that does. |
| C6 | **A companions envelope does carry a hadith card, numbered on its own chain** — `FIRST EDITION nn/39`, never a silsila segment number. Two chains, deliberately separate: the silsila is fourteen and comes only in the box; the companions chain is thirty-nine and is bought a piece at a time. A card must never be able to be read as belonging to the other chain. |

## 9. Sourcing

Full rules in `sourcing-rules.md`. The short form:

| Rule | Check |
|---|---|
| Q1 | Priority order: Tuhaf al-Uqul, then Nahj al-Balagha, Sahifa Sajjadiyya, al-Kafi, Uyun Akhbar al-Rida. |
| Q2 | Published translations, credited by translator and edition. |
| Q3 | Ethics and conduct only. Nothing jurisprudential. Nothing theological. |
| Q4 | Bihar al-Anwar is never the citation of record. |
