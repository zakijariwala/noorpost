# Envelope sign-off checklist

Copy this file into the envelope's folder and fill it. An envelope is not finished because it is written; it is finished when this file is fully ticked and signed.

## Letter

- [ ] 330–370 words. **Counted, not estimated.** Count: ____
- [ ] 6–9 child lines. Count: ____
- [ ] Every child line under 15 words. Longest: ____
- [ ] Adult lines carry the narrative and everything over two sentences
- [ ] Child lines carry only dialogue, questions and beats
- [ ] At least one child line demands a response, and reading cannot continue without it
- [ ] Last line is ●○
- [ ] No names printed, only marks
- [ ] Every child-line word passes the child-word test, or is seeded, or is the one marked exception
- [ ] Read aloud with a stopwatch: ____ minutes (target 4:00–4:30)
- [ ] Does not build to the death
- [ ] No violence in scene, no method, no final hours
- [ ] No moral stated at the end

## Fact panel

- [ ] Six bullets, fixed order
- [ ] Every claim has a row on the citation sheet reading `V`
- [ ] Ruler of the day named, with dynasty
- [ ] Imamate length and starting age both given
- [ ] Woman slot filled, and she does something rather than occupies a position
- [ ] Traditional accounts marked in the child's copy
- [ ] Differ-by-community line used verbatim wherever it applies
- [ ] AH→CE conversion checked twice, by two people
- [ ] Death line last, verbatim from `death-lines.md`, no method, no symptoms
- [ ] Death appears nowhere else in the envelope
- [ ] Source credit carries a number and a named translator
- [ ] No superlatives, no counts of people

## One new thing for the adult

- [ ] Present, and named here: ________________________
- [ ] It is a fact, not a reflection
- [ ] It is checkable
- [ ] It sits in an adult line or the fact panel, where reading aloud will hit it
- [ ] Read to three practising adults. Knew it already: ____ / 3. **Two or more means find another.**

## Through-question

- [ ] How much room he had, in one sentence: ________________________
- [ ] The letter shows what he did inside it
- [ ] The envelope does not resolve into "he was patient"

## Hadith card

- [ ] Sourced in priority order, from the fixed edition
- [ ] Ethics or conduct only. Nothing jurisprudential, nothing theological
- [ ] Quoted exactly. No smoothing, no trimming to fit
- [ ] Silsila segment written, historical order
- [ ] **Segment number printed. Envelope number not printed.**
- [ ] Reads as one chain when stacked with the segments either side of it

## Session card

- [ ] Type matches the assignment
- [ ] Requires two people. **Nothing on it can be done alone.**
- [ ] Conversation: five questions, one marked adult-first, one marked hard-for-an-adult
- [ ] Case File: five evidence cards, sealed answer, opened only on the child's commitment
- [ ] Mourning: one passage, one question, one instruction to sit quietly. No game, no points
- [ ] Needs nothing not in the envelope, except a pen

## Items and physical

- [ ] All seven items present, or six plus a pennant in a mourning issue
- [ ] Person print: A5 portrait, no figures
- [ ] Event print: landscape, standard punch, clips onto the ring with the others
- [ ] Sticker sheet, or pennant in a mourning issue
- [ ] Return postcard, pre-addressed, two signature lines, fixed wording
- [ ] Exterior: circular month cancellation, name area, wax seal
- [ ] Flap block: running order and runtime
- [ ] Nothing in this envelope carries an event print that shouldn't

## Everyone Else only — the companions line (added 2026-08-14)

Skip this section for a box envelope. For a companions envelope, it **replaces** the "Items and physical" list above and amends the hadith card list: five items, not seven, and a different chain.

- [ ] Five items: letter + fact panel, hadith card, person print, sticker sheet, return postcard
- [ ] **No event print.** The calendar ring is box-only and stays that way
- [ ] Person print: a portrait — faces are allowed here, and the line is weaker for not using it
- [ ] Exterior: plain seal, name area, points-home line small. **No month cancellation** — this line is dateless
- [ ] Hadith card: everything in the list above **except** the segment lines, which are replaced by the two below
- [ ] **Chain mark reads `FIRST EDITION nn/39`, written out.** No silsila segment number in any form, front or back
- [ ] Saying is of the Masoom this envelope points home to, theme-matched — **and is not that Masoom's box card**
- [ ] Card and box card side by side: could a child sort them into one pile? If yes, the marks are too alike — `design-system.md` §7
- [ ] Category decision recorded where one is required — Khawla, Fitrus, Ruqayya
