`unusable` is not a guess: it means over half the Arabic runs in that edition carry private-use codepoints or bidi controls, which is what a PDF leaves behind when it hands over positioned glyphs instead of text. **The Arabic in every Arabic-carrying edition here is in that state.** It is preserved verbatim and is never overwritten, but it cannot be quoted, and searching it will mostly fail. The fix needs the original PDFs:

```bash
python tools/build_source_corpus.py --from-pdf --ocr --force-ocr --ocr-lang ara+eng --only SRC-NHB-002
```
