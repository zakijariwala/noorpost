The waitlist

What happens next, in order: one envelope is printed and used with a real family; it goes to madrasa administrators to find out what forty sets would need to cost; if those numbers work, the full run of fourteen is printed; and only then does anything ship or any subscription open.

This form is not open yet. Collecting an address needs a named data controller and a privacy notice, and neither has been set up. The addresses would be handled by a person, not a mailing platform, and nothing else would be sent.
